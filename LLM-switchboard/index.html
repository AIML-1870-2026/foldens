Why Anthropic works differently

Browsers can only call APIs that explicitly permit cross-origin requests (CORS). OpenAI allows this. Anthropic's API is designed to be called from a backend server — so your browser blocks the request before it even reaches Anthropic's servers.

✓ OpenAI
Browser → OpenAI
CORS allowed
✗ Anthropic (direct)
Browser → Anthropic
CORS blocked
✓ Via your server
Browser → Server
→ Anthropic ✓

What this means: You can select Anthropic models and compose prompts — but sending will return a CORS explanation instead of a model response. This is intentional — it's a real engineering constraint, not a bug.
